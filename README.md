# Rovshan Gurbanov — personal website

Built with Astro and designed for GitHub Pages.

## Local development

```powershell
npm install
npm run dev
```

Then open the local URL shown by Astro.

## Production build

```powershell
npm run build
npm run preview
```

## Publish

This project includes a GitHub Actions workflow in `.github/workflows/deploy.yml`.
After pushing the project to `main`, enable **Settings → Pages → Source → GitHub Actions**
in the GitHub repository.
